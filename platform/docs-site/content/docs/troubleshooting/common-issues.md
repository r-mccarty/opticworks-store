## Sensor Won't Connect to Wi-Fi

**Symptoms:** LED stays blue flashing, can't complete setup

**Solutions:**
1. Ensure you're using a 2.4GHz network (not 5GHz)
2. Move closer to your Wi-Fi router
3. Check that your Wi-Fi password is correct
4. Restart your router and try again

{{< hint info >}}
Many dual-band routers broadcast both frequencies with the same name. Try temporarily disabling 5GHz during setup.
{{< /hint >}}

## False Presence Detection

**Symptoms:** Sensor reports presence when room is empty

**Solutions:**
1. Check for moving objects (fans, curtains, pets)
2. Reduce sensitivity in app settings
3. Ensure sensor isn't pointing at windows or reflective surfaces
4. Run manual calibration with room empty

## No Presence Detection

**Symptoms:** Sensor doesn't detect when someone is present

**Solutions:**
1. Verify power connection (LED should be solid blue)
2. Check sensor placement and angle
3. Increase sensitivity in app settings
4. Run manual calibration

## Sensor Offline in App

**Symptoms:** App shows "Offline" or "Disconnected"

**Solutions:**
1. Check power connection
2. Verify Wi-Fi network is working
3. Restart the sensor by unplugging for 10 seconds
4. Check router for IP address conflicts

## Factory Reset

If all else fails, perform a factory reset:

1. Press and hold the reset button for 10 seconds
2. LED will flash red then blue
3. Reconfigure using the app

{{< hint danger >}}
Factory reset erases all settings. You'll need to set up the device again from scratch.
{{< /hint >}}
