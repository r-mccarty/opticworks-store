## What's in the Box

Your OpticWorks package includes everything you need to get started:

- **Presence Sensor** - The main sensing unit
- **Power Adapter** - USB-C power supply (5V/2A)
- **Mounting Hardware** - Screws and adhesive pad for installation
- **Quick Start Guide** - Printed setup instructions

## Before You Begin

1. Check that all items are present
2. Inspect the sensor for any damage
3. Download the OpticWorks app (iOS/Android)
4. Ensure you have a 2.4GHz Wi-Fi network available

{{< hint info >}}
The sensor requires a 2.4GHz Wi-Fi connection. 5GHz networks are not supported for initial setup.
{{< /hint >}}
