The OpticWorks Bed Presence Sensor uses advanced mmWave radar technology to detect presence in bed, sleep states, and breathing patterns—all without cameras or wearables.

## Features

- **Presence Detection** - Know when someone is in bed
- **Sleep State Tracking** - Light sleep, deep sleep, REM detection
- **Breathing Monitoring** - Non-contact respiratory rate tracking
- **Smart Home Integration** - Works with Home Assistant and Matter

## Specifications

| Spec | Value |
|------|-------|
| Technology | 24GHz mmWave radar |
| Range | Up to 3 meters |
| Accuracy | ±5cm presence, ±2 BPM breathing |
| Power | 5V DC, 2W typical |
| Connectivity | Wi-Fi 2.4GHz, Bluetooth LE |
