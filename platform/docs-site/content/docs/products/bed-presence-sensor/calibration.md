## Why Calibrate?

Calibration helps the sensor understand your specific environment:

- Room size and shape
- Bed position and height
- Typical movements vs. presence

## Automatic Calibration

The sensor automatically calibrates during the first 24 hours:

1. Leave the room empty for 30 minutes after setup
2. The sensor will establish a baseline
3. Normal use will refine detection over time

## Manual Calibration

If detection is inaccurate, you can trigger manual calibration:

1. Open the OpticWorks app
2. Go to **Device Settings** → **Calibration**
3. Select **Start Calibration**
4. Follow the on-screen prompts:
   - Empty room for 2 minutes
   - Lie in bed for 2 minutes
   - Exit the room

## Sensitivity Adjustment

Fine-tune detection sensitivity in the app:

- **High** - Detects subtle movements (may increase false positives)
- **Medium** - Balanced setting (recommended)
- **Low** - Requires significant presence (fewer false triggers)

{{< hint warning >}}
After changing sensitivity, allow 24 hours for the sensor to re-learn patterns.
{{< /hint >}}
