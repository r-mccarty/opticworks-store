## Initial Setup

1. **Power on** the sensor using the included USB-C adapter
2. **Open** the OpticWorks app on your phone
3. **Tap** "Add Device" and select "Bed Presence Sensor"
4. **Follow** the in-app instructions to connect to Wi-Fi

## Placement

For bed monitoring, position the sensor:

- **Under the bed** or on a nightstand
- **Pointed toward** the center of the mattress
- **50-100cm** from the edge of the bed

{{< hint tip >}}
The sensor works through mattresses and bedding. No direct line of sight to the person is required.
{{< /hint >}}

## Wi-Fi Connection

1. Ensure your phone is on the same network
2. The sensor will broadcast a setup network (OpticWorks-XXXX)
3. Connect and enter your home Wi-Fi credentials
4. The sensor will reboot and connect automatically

## LED Status

| LED Color | Meaning |
|-----------|---------|
| Blue flashing | Starting up |
| Blue solid | Connected, idle |
| Green pulse | Presence detected |
| Red flashing | Error or offline |
