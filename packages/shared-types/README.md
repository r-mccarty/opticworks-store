# @opticworks/shared-types

Shared TypeScript type definitions for the OpticWorks platform.

## Purpose

This package contains type definitions that are shared across multiple applications and packages in the OpticWorks monorepo, including:

- Product types
- Order and cart types
- User and authentication types
- API request/response types
- Common utility types

## Usage

```typescript
import type { Product, Cart, Order } from '@opticworks/shared-types'
```

## Status

Currently a stub package. Types will be migrated from individual apps as the monorepo architecture matures.
